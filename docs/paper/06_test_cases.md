## 复现命令

```powershell
# 1) 建库（按本机密码调整）
mysql -h127.0.0.1 -uroot -p --default-character-set=utf8mb4 -e "source sql/schema.sql"

# 2) 编译并打包
tools\package.ps1 -Configuration Release

# 3) 启动
dist\LunaChat-Release\Server.exe
dist\LunaChat-Release\Client.exe   # 开两个，分别登录 luna / star
```
