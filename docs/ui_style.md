> 保证"从登录进主界面没有换了一个软件"的感觉。

## 2. 圆角与间距

| 卡片 | 18px | 内容自适应 |

| 窗口按钮 | 18px（圆形） | 36×36 |
| 卡片内边距 | 24px 左右 | 行距 5–10px |

## 3. 字体

- 字族：`Microsoft YaHei UI`，回退 `Microsoft YaHei` / `Segoe UI`
- 标题 26px / 700，副标题 12px，正文 13–14px，说明 11–12px
- 标题字距 1.5px；副标题用空格拉宽字距，营造"月下"氛围

## 4. 交互反馈

- 主按钮：默认紫蓝渐变 → hover 提亮 → pressed 压暗 → disabled 10% 白
- 输入框：默认 1px 10% 白边 → focus 变成 `#8B7BFF` 85% 描边 + 背景提亮
- 卡片切换：淡出 150ms → 新卡片从侧向 18px 滑入 + 淡入 280ms（OutCubic）
- 图标进场：淡入 300ms + 缩放 340ms；上浮 700ms（OutCubic）

## 7. 页面结构约定

- 每个整页：`页头（返回 + 标题 + 副标题）` → `玻璃卡片（表单 / 列表 / 表格）` → `操作栏`
- 主操作按钮用 `#PrimaryButton`（渐变），其余按钮用中性玻璃/白底
- 卡片统一复用 `QFrame#SettingsCard`，页面内边距 18px，卡片内边距 20px
- 标题 15px/700，副标题 11px 次文字色，区块小标题 12px 次文字色

## 9. 动效与状态

- 主页面切换：180ms 透明度淡入，结束后移除 QGraphicsEffect
- 朋友圈：背景按滚动量 15% 慢速上移（视差）；卡片 hover 提亮；右下角渐变悬浮发布按钮
- 空状态：渐变圆形徽章插画（文件夹 / 日历）+ 标题 + 引导文案，有数据后自动切回列表
- 消息列表：按日期插入分隔行，显示“今天 / 昨天 / yyyy 年 M 月 d 日”
- 标题栏：面包屑“LunaChat 月之音 / 当前页面”，返回聊天后恢复“/ 聊天”
## 10. 消息与申请中心

- 入口：群聊工具区四个按钮——新建群组 / 加好友 / 搜索群聊 / 申请消息；申请消息右上角红点显示数量（>99 显示 99+）
- 搜索群聊：独立页面，未输入关键词时展示数据库随机推荐的群（排除已加入、已申请），可搜索、行内“申请加入 / 已申请 / 已加入”
- 申请中心：两个页签“好友申请 / 群聊申请”，页签标题直接带数量
- 好友申请：申请人 + 同意 / 拒绝；拒绝只删除 pending 记录
- 群聊申请：申请人 + 目标群 + 同意 / 拒绝；同意后写入 group_member，并通知申请人
- 加好友：未搜索时展示随机推荐用户（排除自己与已是好友的人），也可直接搜索
- 实时性：friend_notify / group_join_notify 到达时刷新列表
- 朋友圈评论：点评论按钮在帖子下方展开输入框（回车或发送提交），发送后输入框收起，刷新列表显示新评论
- 消息撤回：右键自己两分钟内的消息 → 撤回；气泡替换为“该消息已撤回”
- 删除好友：好友栏右键 / 私聊齿轮 → 统一 ConfirmDialog（DangerButton 红色渐变），确认后双方移除
- 删除评论：右键自己的评论 → 删除评论 → ConfirmDialog，服务端按 commentId + userId 校验
- 好友列表：同时展示在线与离线好友；在线 `●` 正常色，离线 `○` 灰色（#8A82A8），点击离线好友仍可进入私聊
